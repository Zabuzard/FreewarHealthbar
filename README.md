# FreewarHealthbar

Greasemonkey script which adds a visual healthbar to the lifepoints of the
player in the MMORPG [Freewar.de](https://www.freewar.de/).

Import `FreewarHealthbar.user.js` as User-Script in Greasemonkey/Tampermonkey
and start Freewar.
